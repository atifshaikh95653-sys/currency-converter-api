# 💱 Currency Converter

A modern and user-friendly **Currency Converter Web Application** built using HTML, CSS, and JavaScript. It allows users to convert amounts between different currencies using a currency exchange API.

## ✨ Features

- 💱 Real-time currency conversion
- 🌍 Support for multiple currencies
- 🔄 Select source and target currencies
- 💰 Enter custom amount for conversion
- 🌐 Currency Exchange API integration
- ⚡ Fast and easy conversion
- 📱 Responsive and user-friendly design
- 🎨 Clean and modern interface
- 🔁 Easy currency selection and conversion

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Currency Exchange API
- JSON
